# Referências oficiais e técnicas

| Fonte | Link | Observação |
|---|---|---|

| NIST CSF 2.0 | [Acessar](https://www.nist.gov/cyberframework) | Governança e funções do risco cibernético |
| NICE Current Components | [Acessar](https://www.nist.gov/itl/applied-cybersecurity/nice/nice-framework-resource-center/nice-framework-current-versions) | Papéis, competências e tarefas atualizados |
| FIRST CSIRT Framework | [Acessar](https://www.first.org/standards/frameworks/csirts/csirt_services_framework_v2.1) | Catálogo e responsabilidades de equipes de incidentes |
| ATT&CK Detection Strategies | [Acessar](https://attack.mitre.org/detectionstrategies/) | Estratégias DET e analytics AN |
| ATT&CK Analytics | [Acessar](https://attack.mitre.org/analytics/) | Detecção por plataforma |
| ATT&CK Data Model | [Acessar](https://mitre-attack.github.io/attack-data-model/docs/principles/attack-detections/) | Evolução de fontes legadas para novo modelo |
| OCSF | [Acessar](https://github.com/ocsf/ocsf-schema) | Schema de eventos |
| CISA Incident Playbooks | [Acessar](https://www.cisa.gov/topics/cybersecurity-best-practices/executive-order-improving-nations-cybersecurity) | Material útil porém desenvolvido na era NIST rev. 2 |
| SigmaHQ | [Acessar](https://github.com/SigmaHQ/sigma) | Regras comunitárias |
| OTRF ThreatHunter Playbook | [Acessar](https://github.com/OTRF/ThreatHunter-Playbook) | Metodologia hunting |
| AWS IR Playbooks | [Acessar](https://github.com/aws-samples/aws-incident-response-playbooks) | Modelos de cloud IR |

**Atualização metodológica:** NIST 800-61r3 é a edição final vigente desde abril de 2025. ATT&CK v18 (outubro de 2025) evoluiu para Detection Strategies e Analytics; o conceito legado de Data Sources foi depreciado. Valide a versão ao implementar cada regra.
